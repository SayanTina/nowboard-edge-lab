Snowboard Edge Lab

บอร์ดแต่ละ profile ตอบสนองต่อท่าทางผู้ขี่อย่างไร carve หรือ slide ตัดสินจากแรงยึดของ edge เทียบกับแรงที่โค้งต้องการ

R = Rsidecut × cos(มุม edge)
carve เมื่อ m·v²/R ≤ แรงยึด edge

หน้า: หัวกัดหิมะ เข้าโค้งไวและแคบลง แต่ถ้ามากไปหางเบาจนไถลออก (oversteer) ในหิมะผงหัวจะมุด · ท้าย: หัวเบา sidecut ไม่ทำงาน เลี้ยวไม่เข้า หัวไถลออก (understeer) หมุนหัวง่าย ในหิมะผงหัวลอยดี แต่ถ้าเร็วมากบอร์ดพุ่งหลุดจากใต้ตัว

← ไปทาง heelไปทาง toe →
สะโพกอยู่เหนือ edgeนั่งเก้าอี้ ก้นยื่นพ้นบอร์ด

ระหว่างผู้ขี่อัตโนมัติทำงาน ปรับ angulation งอเข่า น้ำหนักหน้า-หลัง และก้นยื่นได้โดยไม่หยุดโหมดอัตโนมัติ (ค่าที่ปักไว้จะมีป้าย "ปักค่าไว้" สีส้ม) ส่วนการเอนและบิดลำตัวใช้เลี้ยว ถ้าลากจะสลับเป็นควบคุมเอง
มุมเอนที่ต้องใช้ = atan(v²/(g·R)) ถ้าเอนเกินกว่านี้มากจะล้มเข้าด้านในโค้ง ถ้าน้อยเกินขณะ edge ยึดแน่นจะถูกเหวี่ยงออก งอเข่ามากช่วยให้ทรงตัวได้ช่วงกว้างขึ้น ส่วนการยื่นก้นตอน heelside ทำให้ลง edge ได้น้อย น้ำหนักไปอยู่ท้ายบอร์ด และช่วงทรงตัวแคบลง

สภาพลาน

เขียว ~8°ดำ ~30°

Catch edge เกิดเมื่อบอร์ดไถลข้างไปทางไหน แล้ว edge ฝั่งนั้น (edge นำ) ถูกกดลงจนจิกหิมะ บอร์ดหยุดกะทันหันแต่ตัวยังพุ่งต่อ Camber เสี่ยงที่สุด Rocker ให้อภัยที่สุดเพราะหัวท้ายยกพ้นหิมะ
